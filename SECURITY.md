# Security policy

Report suspected security or privacy problems through GitHub's private vulnerability reporting when the repository offers it. You can also check [the maintainer's GitHub profile](https://github.com/Threalcocoboy) for private contact options. Keep health records, credentials, signing materials and account identifiers out of public reports. A short description, affected build, device version and synthetic reproduction are sufficient to start.

The stable GitHub release channel will receive fixes as maintenance permits. Use [the release instructions](docs/RELEASING.md) to verify the APK checksum and signing identity.
